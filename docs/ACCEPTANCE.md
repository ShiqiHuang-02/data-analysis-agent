## C. 接入真实模型后的示例任务

请逐条输入，核对工具执行记录是否正常，并保存截图。

1. `请介绍数据的字段、数据量和缺失值。` → 应调用 `overview` 或 `missing_values`。
2. `按地区计算销售额总和，并按总额降序。` → 应调用 `group_aggregate`，示例 4 个地区的数值以本地工具为准。
3. `用日期列按月汇总销售额，并画时间趋势图。` → 应调用 `time_trend`；预期 4 个月份且顺序正确。
4. `用中位数填充客户满意度列的缺失值。` → 应调用 `clean_preview`，并出现待确认的 UI。未确认时数据不应改变；点击确认才生效。再次恢复原始数据验证清洗撤回。
5. `按地区和渠道统计销售额总和、订单数总和和平均客户满意度，按销售额降序。` → `aggregate_table`，三个明确指标，订单数使用 sum。
6. `筛选地区为华北且销售额大于100，按渠道统计销售额总和。` → AND 条件，核对筛选后行数。
7. `统计2026年1月销售额。` → 日期条件为大于等于 2026-01-01、小于 2026-02-01，显式日期类型。
8. 检查上述对话的耗时、工具次数、Token 记录；下载 JSON 可复核参数与结果。Token 未提供时应显示未返回，不能编造零用量。

真实模型可能选错工具或直接回答；请如实记录失败。自动化测试只验证确定性计算与模拟交互，不代表这些自然语言问题已经在真实 API 上全部通过。
